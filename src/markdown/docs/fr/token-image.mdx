# Documentation Cryptometa de Bearby

## Introduction

Cryptometa est un référentiel public utilisé par le portefeuille Bearby pour afficher les informations sur les jetons et calculer leurs scores. Ce référentiel permet aux créateurs de jetons et à la communauté d’ajouter et de mettre à jour les métadonnées des jetons, garantissant une représentation précise et cohérente des jetons dans l’interface du portefeuille Bearby.

## Structure du Référentiel

Le référentiel Cryptometa est organisé comme suit :

```
cryptometa
├── LICENSE
├── README.md
├── ft
│   ├── AS1nqHKXpnFXqhDExTskXmBbbVpVpUbCQVtNSXLCqUDSUXihdWRq
│   │   ├── dark.svg
│   │   ├── light.svg
│   │   └── meta.json
│   ├── AS11111111111111111111116iowaD
│   │   ├── dark.svg
│   │   ├── light.svg
│   │   └── meta.json
│   └── AS111111111111111111111Awmv8x
│       ├── dark.svg
│       ├── light.svg
│       └── meta.json
└── source_code.txt
```

Les principaux composants sont :

- Répertoire `ft` : Contient des sous-répertoires pour chaque jeton fongible, nommés d’après l’adresse du contrat du jeton.
- Chaque répertoire de jeton contient trois fichiers essentiels :
  - `meta.json` : Contient les métadonnées du jeton.
  - `dark.svg` : Icône SVG pour les thèmes en mode sombre.
  - `light.svg` : Icône SVG pour les thèmes en mode clair.

## Comment Ajouter Votre Jeton

Suivez ces étapes pour ajouter votre jeton au portefeuille Bearby :

### 1. Forker le Référentiel

Tout d’abord, forkez le référentiel Cryptometa sur votre compte GitHub.

### 2. Créer un Nouveau Répertoire de Jeton

Dans le répertoire `ft`, créez un nouveau dossier nommé exactement d’après l’adresse du contrat de votre jeton (par exemple, `AS1nqHKXpnFXqhDExTskXmBbbVpVpUbCQVtNSXLCqUDSUXihdWRq`).

### 3. Préparer les Icônes du Jeton

Créez deux icônes SVG pour votre jeton :

- `dark.svg` : L’icône du jeton optimisée pour les interfaces en mode sombre.
- `light.svg` : L’icône du jeton optimisée pour les interfaces en mode clair.

Directives pour les icônes :
- Utilisez le format SVG pour une meilleure mise à l’échelle.
- Maintenez la taille du fichier sous 100 Ko.
- Dimensions recommandées : 128x128 pixels.
- Assurez-vous que les deux icônes sont clairement visibles dans leurs thèmes respectifs.
- Un fond transparent est recommandé.

### 4. Créer le Fichier Meta.json

Créez un fichier `meta.json` dans le répertoire de votre jeton avec la structure suivante :

### 5. Soumettre une Demande de Tirage

Une fois que vous avez ajouté le répertoire de votre jeton avec tous les fichiers requis, validez les modifications et soumettez une demande de tirage au référentiel principal Cryptometa.

## Champs Obligatoires et Optionnels

Le fichier meta.json contient plusieurs champs qui aident le portefeuille Bearby à évaluer et afficher votre jeton. Voici une répartition des champs et de leur importance :

| Champ               | Obligatoire | Points | Notes                                                     |
|---------------------|----------|--------|-----------------------------------------------------------|
| name                | Oui      | -      | Le nom complet de votre jeton                            |
| symbol              | Oui      | -      | Le symbole du jeton                       |
| description         | Non       | -      | Une brève description du projet                        |
| decimals            | Non       | -      | Nombre de décimales pour le jeton                   |
| supply              | Non       | -      | Offre totale de jetons                                        |
| web                 | Non       | 5      | Site web du projet (doit utiliser https)                        |
| email               | Non       | -      | Email de contact de l’équipe                                |
| whitepaper          | Non       | 10     | Lien vers un livre blanc complet                        |
| holders             | Non       | 10     | Définir à true si plus de 1000 détenteurs sans airdrops  |
| publicTeam          | Non       | 20     | Définir à true si les membres de l’équipe sont publics        |
| product             | Non       | 30     | Définir à true s’il existe un produit utilisable   |

## Calcul du Score des Jetons

Bearby utilise les informations du fichier meta.json pour calculer un score pour chaque jeton. Ce score aide les utilisateurs à identifier les jetons plus fiables et établis.

Le score maximum possible est de 110 points, répartis comme suit :
- Site web (https) : 5 points
- Livre blanc : 10 points
- Plus de 1000 détenteurs : 10 points
- Équipe publique : 20 points
- Produit fonctionnel : 30 points
- Liens de recherche : 10 points
- GitHub avec dépôts liés : 10 points
- LinkedIn avec équipe visible : 10 points
- Présence sur X/Twitter : 5 points

Les jetons avec des scores plus élevés seront considérés comme plus fiables dans l’interface du portefeuille Bearby.

## Processus de Révision

Après avoir soumis votre demande de tirage, l’équipe Bearby examinera votre soumission pour s’assurer qu’elle répond à toutes les exigences. Ils peuvent demander des informations supplémentaires ou des modifications avant d’approuver votre jeton.

Le processus de révision comprend généralement:

1. Vérification de l’adresse du contrat du jeton.
2. Validation des métadonnées du jeton.
3. Examen de la qualité et de l’adéquation des icônes du jeton.
4. Confirmation des liens et autres informations fournies.

## Mise à Jour des Informations Existantes sur un Jeton

Pour mettre à jour les informations d’un jeton existant :

1. Forkez le référentiel.
2. Apportez les modifications nécessaires aux fichiers du jeton.
3. Soumettez une demande de tirage avec une explication claire des modifications.

## Meilleures Pratiques

- Assurez-vous que tous les liens sont valides et pointent vers des ressources officielles.
- Utilisez des icônes SVG de haute qualité pour un affichage optimal dans le portefeuille.
- Fournissez des informations précises et complètes dans le fichier meta.json.
- Gardez les descriptions concises mais informatives.
- Mettez à jour les informations de votre jeton en cas de changements significatifs.

## Notes Importantes

- L’équipe Bearby a le dernier mot concernant l’approbation des jetons et leurs scores pour protéger les utilisateurs.
- Des informations trompeuses peuvent entraîner le rejet ou la suppression de votre jeton.
- Les jetons avec des scores plus élevés peuvent bénéficier d’une meilleure visibilité dans l’interface du portefeuille.
- Des mises à jour régulières des informations de votre jeton sont encouragées à mesure que votre projet évolue.

## Support

Si vous avez des questions sur l’ajout de votre jeton ou besoin d’assistance avec le processus, vous pouvez contacter l’équipe Bearby via leurs canaux officiels.
