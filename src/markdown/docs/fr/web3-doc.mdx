# Bibliothèque Bearby Web3

## Introduction

Bearby Web3 est le module web3 principal pour le portefeuille Bearby, conçu pour permettre aux développeurs d'interagir facilement avec la blockchain Massa via l'interface du portefeuille Bearby. Cette bibliothèque fournit un ensemble complet d'outils et d'APIs pour développer des applications web3 sur la blockchain Massa.

## Installation

```bash
# Avec yarn
yarn add @hicaru/bearby.js

# Avec npm
npm install @hicaru/bearby.js
```

## Modules Principaux

La bibliothèque Bearby Web3 se compose des modules principaux suivants :

| Module          | Description                                                                        |
|-----------------|------------------------------------------------------------------------------------|
| `web3.wallet`   | Gère la connexion au portefeuille, les comptes, les opérations de signature et les informations réseau |
| `web3.contract` | Gère les interactions avec les contrats intelligents (déploiement, appel, lecture) |
| `web3.massa`    | Fournit un accès direct aux méthodes JsonRPC de la blockchain Massa                |

## Premiers Pas

La bibliothèque est conçue pour fonctionner exclusivement dans des environnements de navigateur et fournit un objet global bearby après l'initialisation.

```javascript
import { web3 } from '@hicaru/bearby.js';

// Vous pouvez maintenant accéder à l'objet web3
console.log(web3.wallet.connected); // Vérifie si le portefeuille est connecté
```

## Module : web3.wallet

Le module portefeuille gère toutes les opérations liées au portefeuille, y compris les connexions, la gestion des comptes et la signature des transactions.

### Propriétés

| Propriété   | Type         | Description                                                                 |
|-------------|--------------|-----------------------------------------------------------------------------|
| `connected` | `boolean`    | Indique si le site web est actuellement connecté au portefeuille            |
| `enabled`   | `boolean`    | Indique si le portefeuille est déverrouillé                                 |
| `installed` | `boolean`    | Indique si l'extension du portefeuille Bearby est installée                 |
| `account`   | `Account`    | Fournit un accès au compte actuel et aux méthodes associées                 |
| `network`   | `Network`    | Fournit un accès au réseau actuel et aux méthodes associées                 |
| `blockchain`| `Blockchain` | Fournit un accès aux données de la blockchain, comme la période actuelle    |


### Méthodes

#### connect()

Initie une connexion entre le site web et le portefeuille Bearby. Affiche une fenêtre contextuelle où l'utilisateur peut approuver ou rejeter la connexion.

```javascript
try {
  const connected = await web3.wallet.connect();
  if (connected) {
    console.log("Connecté au portefeuille Bearby !");
    console.log("Adresse actuelle:", web3.wallet.account.base58);
  }
} catch (error) {
  console.error("Échec de la connexion:", error.message);
}
```

#### disconnect()

Déconnecte le site web du portefeuille Bearby.

```javascript
try {
  const disconnected = await web3.wallet.disconnect();
  console.log("Déconnecté du portefeuille Bearby:", disconnected);
} catch (error) {
  console.error("Échec de la déconnexion:", error.message);
}
```

#### signMessage(message)

Signe un message en utilisant le compte actuel.

```javascript
try {
  const signedMessage = await web3.wallet.signMessage("Bonjour, Massa !");
  console.log("Signature:", signedMessage.signature);
  console.log("Clé publique:", signedMessage.publicKey);
  console.log("Message original:", signedMessage.message);
} catch (error) {
  console.error("Échec de la signature:", error.message);
}
```

#### signTransaction(transaction)

Signe une transaction en utilisant le compte actuel. La transaction doit être une instance de la classe Transaction

```javascript
import { Transaction } from '@hicaru/bearby.js';
// ou créez une transaction en utilisant les méthodes web3.contract ou web3.massa

try {
  const txHash = await web3.wallet.signTransaction(transaction);
  console.log("Hash de la transaction:", txHash);
} catch (error) {
  console.error("Échec de la signature de la transaction:", error.message);
}
```

#### isMassaAddress(address)

Vérifie si une adresse est une adresse valide de la blockchain Massa.

```javascript
const isValid = await web3.wallet.isMassaAddress("A12KqAUVvPZAAybdmJijkKbynfJeDUsfztEUh8JCSx6DPjczdYLt");
console.log("Est une adresse Massa valide:", isValid);
```

#### requestPubKey()

Demande la clé publique du compte actuellement connecté.

```javascript
try {
  const pubKey = await web3.wallet.requestPubKey();
  console.log("Clé publique :", pubKey);
} catch (error) {
  console.error("Échec de l'obtention de la clé publique :", error.message);
}
```

### Abonnement au Compte

L'objet compte permet de s'abonner aux modifications du compte actuel.

```javascript
// S'abonner aux modifications du compte
const observer = web3.wallet.account.subscribe((base58, accounts) => {
  console.log("Compte actif :", base58);
  console.log("Comptes disponibles :", accounts);
});

// N'oubliez pas de vous désabonner lorsque cela n'est plus nécessaire pour éviter les fuites de mémoire
observer.unsubscribe();
```

### Abonnement au Réseau

L'objet réseau permet de s'abonner aux modifications du réseau.

```javascript
// S'abonner aux modifications du réseau
const observer = web3.wallet.network.subscribe((networkName) => {
  console.log("Réseau actuel :", networkName);
});

// N'oubliez pas de vous désabonner lorsque cela n'est plus nécessaire
observer.unsubscribe();
```

### Abonnement à la Blockchain

L'objet blockchain permet de s'abonner aux mises à jour de la période de la blockchain.

```javascript
// S'abonner aux modifications de la période
const observer = web3.wallet.blockchain.subscribe((period) => {
  console.log("Période actuelle :", period);
});

// N'oubliez pas de vous désabonner lorsque cela n'est plus nécessaire
observer.unsubscribe();
```

## Module: web3.contract

Le module contrat fournit des méthodes pour interagir avec les contrats intelligents sur la blockchain Massa.

### Méthodes

#### deploy(params)

Déploie un contrat intelligent sur la blockchain Massa.

```javascript
try {
  const txHash = await web3.contract.deploy({
    fee: 0, // Frais de transaction
    maxGas: 4_200_000_000, // Gaz maximum pour le déploiement du contrat
    maxCoins: 0.1 * 10**9, // Maximum de pièces à dépenser
    coins: 100000000n, // Pièces à attacher au déploiement du contrat
    parameters: [ // Paramètres du constructeur (facultatif)
      {
        type: web3.contract.types.STRING,
        value: "Bonjour, le monde !"
      }
    ],
    deployerBase64: "AGFzbQEAAAABWA9gAX8Bf2AAAGACf38AAAAAAAAAAAIAAAACAAAAA=", // Code binaire du déployeur encodé en Base64
    contractDataBase64: "AGFzbQEAAAABKQhgAX8AYAJ/fbWFw" // Code binaire du contrat encodé en Base64
  });
  console.log("Hash de la transaction de déploiement :", txHash);
} catch (error) {
  console.error("Échec du déploiement du contrat :", error.message);
}
```

#### call(params)

Appelle une fonction sur un contrat intelligent déployé.

```javascript
try {
  const txHash = await web3.contract.call({
    fee: 0, // Frais de transaction
    maxGas: 2000000, // Gaz maximum pour l'appel de fonction
    coins: 0, // Pièces à attacher à l'appel de fonction
    targetAddress: 'A12KqAUVvPZAAybdmJijkKbynfJeDUsfztEUh8JCSx6DPjczdYLt', // Adresse du contrat
    functionName: 'transfer', // Fonction à appeler
    parameters: [ // Paramètres de la fonction
      {
        type: web3.contract.types.STRING,
        value: "Bonjour, le monde !"
      },
      {
        type: web3.contract.types.BOOL,
        value: true
      },
      {
        type: web3.contract.types.F64,
        value: 32
      },
      {
        type: web3.contract.types.U256,
        value: '435435345234324324324323243242398854684'
      }
    ]
  });
  console.log("Hash de la transaction d'appel de fonction :", txHash);
} catch (error) {
  console.error("Échec de l'appel de fonction :", error.message);
}
```

Alternativement, vous pouvez utiliser unsafeParameters avec le sérialiseur Args de Massa :

```javascript
import { Args } from "@massalabs/massa-web3";

const args = new Args()
  .addString("Bonjour le monde")
  .addBool(true)
  .addF64(0.3);

try {
  const txHash = await web3.contract.call({
    maxGas: 2000000,
    coins: 0,
    targetAddress: 'A12KqAUVvPZAAybdmJijkKbynfJeDUsfztEUh8JCSx6DPjczdYLt',
    functionName: 'transfer',
    unsafeParameters: args.serialize()
  });
  console.log("Hash de la transaction d'appel de fonction :", txHash);
} catch (error) {
  console.error("Échec de l'appel de fonction :", error.message);
}
```

#### readSmartContract(params)

Effectue un appel en lecture seule à une fonction de contrat intelligent.

```javascript
try {
  const data = await web3.contract.readSmartContract({
    fee: 0, // Frais de transaction (non requis pour les appels en lecture seule)
    maxGas: 200000, // Gaz maximum pour l'opération de lecture
    simulatedGasPrice: 0, // Prix du gaz pour la simulation
    targetAddress: 'A12KqAUVvPZAAybdmJijkKbynfJeDUsfztEUh8JCSx6DPjczdYLt', // Adresse du contrat
    targetFunction: "balanceOf", // Fonction à appeler
    parameter: [] // Paramètres de la fonction
  });
  console.log("Résultat de la lecture :", data);
} catch (error) {
  console.error("Échec de la lecture :", error.message);
}
```

#### getFilteredSCOutputEvent(filter)

Récupère les événements émis par un contrat intelligent en fonction d'un filtre.

```javascript
try {
  const eventsFilter = {
    start: null, // Slot de départ
    end: null, // Slot de fin
    original_caller_address: null, // Filtre d'adresse de l'appelant original
    original_operation_id: 'txHash', // Filtre de hash de transaction
    emitter_address: null, // Filtre d'adresse du contrat
  };
  
  const response = await web3.contract.getFilteredSCOutputEvent(eventsFilter);
  
  if (response && response.result && response.result[0] && response.result[0].data) {
    const eventData = String(response.result[0].data);
    console.log("Données de l'événement :", eventData);
  }
} catch (error) {
  console.error("Échec de la récupération des événements :", error.message);
}
