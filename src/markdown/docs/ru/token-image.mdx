# Документация Bearby Cryptometa

## Введение

Cryptometa — это открытое хранилище, которое используется кошельком Bearby для отображения информации о токенах и расчёта их рейтингов. Это хранилище позволяет создателям токенов и сообществу добавлять и обновлять метаданные токенов, обеспечивая точное и единообразное отображение информации в интерфейсе кошелька Bearby.

## Структура репозитория

Репозиторий cryptometa организован следующим образом:

```
cryptometa
├── LICENSE
├── README.md
├── ft
│   ├── AS1nqHKXpnFXqhDExTskXmBbbVpVpUbCQVtNSXLCqUDSUXihdWRq
│   │   ├── dark.svg
│   │   ├── light.svg
│   │   └── meta.json
│   ├── AS11111111111111111111116iowaD
│   │   ├── dark.svg
│   │   ├── light.svg
│   │   └── meta.json
│   └── AS111111111111111111111Awmv8x
│       ├── dark.svg
│       ├── light.svg
│       └── meta.json
└── source_code.txt
```

Ключевые компоненты:

- Каталог `ft`: содержит подпапки для каждого FT токена, названные по адресу смарт-контракта токена.
- Каждая папка токена содержит три обязательных файла:
  - `meta.json`: содержит метаданные токена
  - `dark.svg`: иконка для тёмной темы
  - `light.svg`: иконка для светлой темы

## Как добавить свой токен

Следуйте этим шагам, чтобы добавить свой токен в кошелёк Bearby:

### 1. Сделайте форк репозитория

Сначала сделайте форк репозитория Cryptometa в своём GitHub аккаунте.

### 2. Создайте директорию токена

Внутри папки `ft` создайте новую директорию с точным названием адреса смарт-контракта вашего токена (например, `AS1nqHKXpnFXqhDExTskXmBbbVpVpUbCQVtNSXLCqUDSUXihdWRq`).

### 3. Подготовьте иконки токена

Создайте две SVG иконки:

- `dark.svg`: оптимизированная для тёмной темы
- `light.svg`: оптимизированная для светлой темы

Рекомендации по иконкам:
- Формат: SVG для масштабируемости
- Размер: до 100KB
- Рекомендуемое разрешение: 128x128 пикселей
- Иконки должны хорошо отображаться в соответствующей теме
- Рекомендуется использовать прозрачный фон

### 4. Создайте файл meta.json

Создайте файл `meta.json` в папке токена со следующей структурой:

```json
{
  "name": "Имя вашего токена",
  "symbol": "TOKEN",
  "description": "Краткое описание токена и его назначения",
  "decimals": 9,
  "supply": 1000000000,
  "web": "https://yourwebsite.com",
  "email": "contact@yourproject.com",
  "whitepaper": "https://yourwebsite.com/whitepaper.pdf",
  "holders": true,
  "publicTeam": true,
  "product": true,
  "links": {
    "github": "https://github.com/yourproject",
    "linkedin": "https://linkedin.com/company/yourproject",
    "x": "https://x.com/yourproject",
    "coinmarketcap": "https://coinmarketcap.com/currencies/yourtoken",
    "coingecko": "https://coingecko.com/en/coins/yourtoken",
    "medium": "https://medium.com/@yourproject",
    "blog": "https://yourwebsite.com/blog",
    "telegram": "https://t.me/yourproject",
    "discord": "https://discord.gg/yourproject",
    "facebook": "https://facebook.com/yourproject",
    "reddit": "https://reddit.com/r/yourproject",
    "youtube": "https://youtube.com/c/yourproject",
    "instagram": "https://instagram.com/yourproject"
  }
}
```

### 5. Отправьте Pull Request

После добавления папки токена со всеми необходимыми файлами, зафиксируйте изменения и отправьте pull request в основной репозиторий Cryptometa.

## Обязательные и необязательные поля

Файл `meta.json` содержит несколько полей, которые помогают кошельку Bearby отображать ваш токен и присваивать ему рейтинг. Ниже приведена таблица с описанием полей:

| Поле               | Обязательно | Баллы | Примечания                                                                       |
|--------------------|-------------|--------|-----------------------------------------------------------------------------------|
| `name`             | Да          | -      | Полное имя токена                                                                |
| `symbol`           | Да          | -      | Биржевой тикер токена                                                            |
| `description`      | Нет         | -      | Краткое описание проекта                                                         |
| `decimals`         | Нет         | -      | Количество знаков после запятой                                                  |
| `supply`           | Нет         | -      | Общий объём токенов                                                              |
| `web`              | Нет         | 5      | Веб-сайт проекта (только `https`)                                                |
| `email`            | Нет         | -      | Контактный email команды                                                         |
| `whitepaper`       | Нет         | 10     | Ссылка на подробный whitepaper                                                   |
| `holders`          | Нет         | 10     | Установите `true`, если более 1000 держателей без airdrop                        |
| `publicTeam`       | Нет         | 20     | Установите `true`, если у команды есть публичные профили                         |
| `product`          | Нет         | 30     | Установите `true`, если есть рабочий продукт                                     |


### Поля со ссылками

Объект `links` может содержать следующие свойства:

| Поле ссылки      | Баллы | Примечания                                                      |
|------------------|--------|------------------------------------------------------------------|
| `research`       | 10     | Ссылки на Binance Research, TokenData и т.п.                    |
| `github`         | 10     | Аккаунт или организация с репозиториями проекта                 |
| `linkedin`       | 10     | Должны быть видны участники команды                             |
| `x`              | 5      | Аккаунт проекта в X/Twitter                                     |
| `coinmarketcap`  | -      | Страница токена на CoinMarketCap                               |
| `coingecko`      | -      | Страница токена на CoinGecko                                   |
| `medium`         | -      | Публикации на Medium                                           |
| `blog`           | -      | Блог проекта                                                   |
| `telegram`       | -      | Официальная группа в Telegram                                  |
| `discord`        | -      | Официальный сервер Discord                                     |
| `facebook`       | -      | Страница проекта в Facebook                                    |
| `reddit`         | -      | Официальный сабреддит                                          |
| `youtube`        | -      | Канал проекта на YouTube                                       |
| `instagram`      | -      | Аккаунт проекта в Instagram                                    |


## Расчёт рейтинга токена

Кошелёк Bearby использует информацию из файла `meta.json` для расчёта рейтинга токена. Это помогает пользователям определять более надёжные и зрелые проекты.

Максимальный возможный балл — 110:

- Веб-сайт (https): 5 баллов  
- Whitepaper: 10 баллов  
- 1000+ держателей: 10 баллов  
- Публичная команда: 20 баллов  
- Рабочий продукт: 30 баллов  
- Research-ссылки: 10 баллов  
- GitHub с релевантными репозиториями: 10 баллов  
- LinkedIn с публичной командой: 10 баллов  
- Наличие X/Twitter: 5 баллов  

Токены с более высоким рейтингом считаются более надёжными в интерфейсе Bearby.

## Процесс рассмотрения

После отправки pull request команда Bearby проверит вашу заявку на соответствие требованиям. Могут быть запрошены дополнительные сведения или исправления.

Процесс включает:
1. Проверку адреса контракта токена  
2. Валидацию метаданных  
3. Оценку качества иконок  
4. Подтверждение предоставленных ссылок и данных

## Обновление информации токена

Чтобы обновить данные уже добавленного токена:

1. Сделайте форк репозитория  
2. Внесите необходимые изменения  
3. Отправьте pull request с пояснением изменений

## Рекомендации

- Убедитесь, что все ссылки рабочие и ведут на официальные ресурсы  
- Используйте качественные SVG иконки  
- Вносите точную и подробную информацию в meta.json  
- Описания должны быть короткими, но содержательными  
- Обновляйте данные токена при изменениях в проекте

## Важные замечания

- Команда Bearby оставляет за собой право одобрять или отклонять токены и их рейтинги  
- Ложная информация может привести к отклонению или удалению токена  
- Токены с высоким рейтингом могут получать больше внимания в интерфейсе  
- Регулярное обновление информации о токене приветствуется

## Поддержка

Если у вас есть вопросы по добавлению токена или вам нужна помощь, свяжитесь с командой Bearby через официальные каналы.
