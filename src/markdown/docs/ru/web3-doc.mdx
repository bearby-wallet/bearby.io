## Введение

Bearby Web3 — это основной модуль web3 для кошелька Bearby, предназначенный для упрощённого взаимодействия с блокчейном Massa через интерфейс кошелька. Библиотека предоставляет обширный набор инструментов и API для создания web3-приложений на блокчейне Massa.

## Установка

```bash
# С использованием yarn
yarn add @hicaru/bearby.js

# С использованием npm
npm install @hicaru/bearby.js
```

## Основные модули

Библиотека Bearby Web3 включает в себя следующие основные модули:

| Модуль | Описание |
|--------|----------|
| `web3.wallet` | Управление подключением кошелька, аккаунтами, подписями и информацией о сети |
| `web3.contract` | Взаимодействие со смарт-контрактами (развёртывание, вызов, чтение) |
| `web3.massa` | Прямой доступ к методам JsonRPC блокчейна Massa |

## Начало работы

Библиотека работает только в браузере и предоставляет глобальный объект `bearby` после инициализации.

```javascript
import { web3 } from '@hicaru/bearby.js';

// Теперь можно использовать объект web3
console.log(web3.wallet.connected); // Проверка подключения кошелька
```
